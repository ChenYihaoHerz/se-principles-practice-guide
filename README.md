# 系统工程原理与实践 · 中文导读

Alexander Kossiakoff、Samuel J. Seymour、David A. Flanigan、Steven M. Biemer 所著《Systems Engineering Principles and Practice》（第三版，Wiley，2020）的中文交互式导读。

在线阅读：https://chenyihaoherz.github.io/se-principles-practice-guide/

## 内容

- 每章一个页面，章节编号与原书一致；第 1～12 章精读，其余各章略读，但重要部分写得详细。
- 关键术语可以展开查看中英文名称和释义。
- 正文里有可交互的示意图、分步演示、分类练习和情境模拟，每章末尾有小测验。
- 全书概念图按概念而不是按章节组织，随着阅读进度逐步展开，每个概念都有释义、例子、与其他概念的关系和相关章节。
- 阅读进度和测验答案只保存在浏览器本地。

## 构建

源文件在 `src/`，执行下面的命令生成 `docs/`（GitHub Pages 从 `docs/` 发布）：

```bash
node build.js
```

不需要安装任何依赖。
